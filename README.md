# Beya - Online Shopping Website

Beya is a React-based online shopping website developed as a project assignment.

## Features

- Home page with a banner carousel
- Product categories and special offers
- Product listing using the Fake Store API
- Product details page
- Add to Cart functionality
- Shopping cart with quantity controls
- Cart data managed using React Context
- About Us page
- Contact Us page
- Login page

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Bootstrap
- React Router
- React Context API
- Fake Store API
